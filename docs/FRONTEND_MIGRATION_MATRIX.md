## 尚未完成的生产能力

页面级迁移完成不代表 Web 功能与线上数据已经完整迁移。以下能力继续保持关闭：

- 真实注册、登录、Token 存储和跨设备同步；
- 线上卡片目录、排行、指标与文章 API；
- 推荐、纠错、留言的服务端提交、处理进度与回复同步；
- 完整英文文案及运行时语言切换；
- Web 管理后台。

正式启用前必须分别完成接口安全、隐私、错误状态、离线行为与数据来源审查。
