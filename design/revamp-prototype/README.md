# CardFi 改版原型

打开 `index.html` 即可离线体验，也可以通过本机预览地址 `http://127.0.0.1:8766/` 查看。

页面包含：

- 新旧对照：当前安卓实拍与新版找卡页，并标记五处主要变化。
- 可点击原型：找卡、地区与类型筛选、搜索、详情、两卡对比、发现、攻略及收藏演示。
- 页面总览：找卡、对比、发现三个页面的整体效果。

差异编号：

1. 首屏显示搜索框。
2. 将“其他”改为“银行卡”、“更多”改为“其他地区”，补充筛选入口。
3. 缩小列表卡面与支付标识，完整显示名称，分别展示地区、资格和费用状态。
4. 在列表直接选卡，并通过浮动栏进入两卡对比。
5. 底部导航添加文字：卡包、找卡、发现、我的。

资料和交互说明：

- 当前版本使用 2026-10-06 的 Android 截图。
- 卡名及卡面来自项目现有资源。公开目录中的费用、资格缺失时，原型显示“待核验”，不填造费用或推断可申请资格。
- 攻略与资料更新为内容结构示例。真实的规则变更摘要需要资料版本、核验记录和差异数据。
- 收藏与保存反馈仅在原型内演示，不写入真实账号，不接入登录、支付或推送。
- 原型为设计审阅产物，未替换 Flutter App 页面；正式界面仍使用 Flutter 原生组件。

已检查地区切换、搜索、两卡对比、只看不同、详情返回、资料状态筛选、攻略跳转、差异标记开关和 360px 窄屏。

`index.html` 包含全部图片和交互，不需要网络或安装依赖。`build-prototype.cjs` 用于从模板与现有本机资源重新生成它。
